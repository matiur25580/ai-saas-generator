# Staging Preview Validation

This branch exists to trigger an isolated Vercel Preview deployment for validating the
frontend against the Render staging API.

## Environment routing

- Vercel Production: `VITE_BACKEND_URL=https://ai-saas-generator-d3g8.onrender.com`
- Vercel Preview: `VITE_BACKEND_URL=https://ai-saas-generator-staging-ko-ji.onrender.com`

Do not change the Production environment variable when testing staging.

## Validation

1. Wait for the Vercel Preview deployment generated by this pull request.
2. Open the Preview URL and confirm its browser network requests target the staging API host.
3. Log in using the dedicated staging test account.
4. Run the GitHub Actions workflow **Staging Authentication Smoke Test**.
5. Confirm login, refresh-token rotation, logout, and revoked-token rejection all pass.

Never include credentials or secret values in this document, pull request, or logs.
